# The Roottrees are Dead — 资料归档

> 归档日期：2026-11-07
> 用途：素材，不是成稿。这个游戏有个特殊之处：**它有两个版本，事实很容易搞混。**

---

## 一、先分清两个版本（这是最容易写错的地方）

| | 免费版 | Steam 版 |
|---|---|---|
| 时间 | 2023-11-07（itch.io） | 2025-01-15 |
| 起因 | Global Game Jam 2023，**一周内做出原型** | 之后又花了 11 个月扩写 |
| 作者 | Jeremy Johnston | 移交 Robin Ward 用 **Godot 重写** |
| 美术 | **AI 生成**（Midjourney）——这也是它免费的原因 | 换成桌游画师 **Henning Ludvigsen** 的手绘 |
| 价格 | 免费 | $19.99（首发 -10%） |
| 发行 | 自发布 | Evil Trout Inc. |

**关键因果**：免费版用了 AI 图，所以不能收费。Steam 版重做了美术，才敢卖 19.99。

> 这条在做"AI 生成内容的商业后果"这个题目时很有用：**AI 图让一个游戏只能免费发，重画之后才能定价。**

## 三、剧情设定（写文章当开头用）

```
1998 年 12 月，Carl Roottree（Roottree 糖果公司总裁）与妻子、
三个女儿（Rhayna / Rhose / Rhiley，都是模特）一起死于私人飞机失事。
五人合计身家超过 10 亿美元。

公司创始人 Elias Roottree 在遗嘱里规定：
公司收益在**所有血亲后代**之间平分，不论隔多少代。

于是问题变成：谁还算 Roottree 家的人？

空难两天后，一个匿名客户找上门（玩家），
委托把整个家族树查清楚。
```

**注意名字拼写**：Rhayna / Rhose / Rhiley——三个都 R 开头，是刻意设计（增加混淆难度）。

## 四、机制：这是全文最该写细的部分

### ① 你的工具只有三样

```
电脑（拨号上网）     SpiderSearch 搜索引擎
                    —— 1998 年的搜索，只能搜到"有名的"家族成员
图书馆               必须**先知道书名和作者**才能借
期刊库               **必须先在别处看到这本杂志的名字**，它才会进库
```

**这三条限制是整个游戏设计的核心**：
> 不是"搜不到"，是"你得先知道该搜什么"。

### ② 不是打字，是划词

界面全建立在**鼠标划选**上：

```
在网页/书/证据上划一段文字 → 可以
   a) 直接拿去搜
   b) 或者在旁边弹出的笔记本里生成一条带**回链**的笔记
```

**不用打字**（这个细节很重要：它把"检索"变成"翻找"，不是"输入"）。

### ③ 三条帮助机制（这三条是设计亮点）

| 机制 | 触发 | 作用 |
|---|---|---|
| 证据直觉 | 每份证据右上角显示一个数字 | 告诉你有几条**还没用上的**线索。可关闭 |
| 锁定 | 一次答对 3 个人 | 这 3 条锁定，防止你反复改。**越往后要答对越多才能锁定** |
| 橡皮鸭 | 你主动问 | 第一次给全局提示，第二次给更具体的（比如"该搜什么词"）|

**can i play that? 的评测原话**：
> "最重要的是，游戏从不因为你求助而惩罚你。"

**这是可访问性设计的一个正面样本**，值得单独写一段。

### ④ 惩罚设计

- **答错不锁**，但正确答案不确认
- 越往后线索越难找，但"剩下的名字和照片能去的地方也越少"——**排除法自然收紧**
- 有些评测提到：错判会**清空你的工作清单**（这一条来自 escapegaming 对 Database Detective 的描述，不是本作，别搞混）

### ⑤ 档案袋与打印机

游戏会自动打印"值得打印"的东西（带照片的文章、杂志封面），摆在桌上，可以一键在"屏幕 / 桌面"之间切换。

**这个设计的作用**：让"两个屏"变成叙事工具，而不是 UI 便利。

## 五、流传最广的一句评价

Robin Ward（接手重做的开发者）第一次看到免费版时的说法：

> **"Her Story meets Return of the Obra Dinn meets The Case of the Golden Idol"**

**这句话本身就是这个类型的坐标系。** 三个锚点各代表一种机制：

```
Her Story      数据库关键词检索
Obra Dinn      从碎片推身份（并且要三条一起确认）
Golden Idol    从场景里凑出句子/关系
```

**Roottrees 把三个都吃了。** 这是解释"Fake OS 到底是什么"最好的一个入口。

## 六、评价与批评（一起写才站得住）

**正面（thinkygames）**：
> "作为一个谜题，这棵家族树令人极为满足，是一窝互相缠绕的兔子洞：你在一条里挖到不能再挖，过程中发现好几条新的，然后跳进下一条。"

**正面（hard-drive）**：

**批评（必须写）**：
- **hard-drive**："偶尔依赖 moon logic。第一案里有几处关键，只能靠一个大直觉跳过去——比如一眼判断两个几乎一样的人谁更老。"
- **adventuregamehotspot**："接近结尾时有几处解法特别刁钻，几乎接近不公平。"
- **thinkygames**："作为叙事体验，它的野心不如它的谜题。"
- **caniplaythat**："文字大小只能调一部分，无屏幕阅读器，无手柄支持。"

**thinkygames 还有一句我特别喜欢**（可以当引文）：
> "它主动嘲笑了 Reddit 式网络侦探那套做法，以及那套做法怎么把人带进阴暗又离谱的地方。"

## 七、开发史（薄，但有两点）

1. **一周做原型**：Global Game Jam 2023，Jam 的时间压力下他原本想找朋友画图（那时生成式 AI 还不普及）
2. **11 个月扩写**，然后 Robin Ward 发现它、联系、重写

**Robin Ward 的背景**：Discourse 论坛软件的开发者，之前做过 Forumwarz（一个 2000 年代恶搞论坛的浏览器游戏）。

> **这条线索有意思**：做论坛软件的人，接手了一个关于"翻旧资料"的游戏。

---

## 八、可以写的角度（候选）

1. **"你得先知道该搜什么"**——1998 年的搜索限制，反而成了最好的谜题设计
2. **三条帮助机制**——一个从不惩罚求助的游戏，怎么做到不发水
3. **AI 图 → 只能免费 → 重画 → 才敢卖 19.99**：一个可量化的商业因果
4. **Her Story + Obra Dinn + Golden Idol**：这个类型的三条基因，被一个游戏合起来了
