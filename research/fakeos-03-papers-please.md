## 二、机制：为什么它是"被动等人上门"的源头

### 核心循环（一天一轮）

```
每天上班 → 队伍开始走 → 每个人递证件 → 你核对 → 放行/拒签 → 盖章
下班 → 结算工资（房租、食物、供暖、医药）→ 睡觉 → 第二天规则变了
```

**关键设计：你不动。是别人走向你。**

**方向感完全反转**：不是你去翻资料，是资料（和人）排队来找你。

### 每天变的规则（这是难度的真正来源）

**政府每天发新规定**：
```
新增一种证件
某一类人禁止入境
印章从"拒绝"改成"扣留"
指纹 / 体态扫描仪上线
```

**Nintendo 系的评测原文**（转述）：
> "找差异这个游戏越来越复杂：规则每天按政府规定变化，证件类型越来越刁钻，上级还在盯着，一有错就给你记一次"

### 惩罚机制（这一条最狠）

**记过 → 扣工资 → 家里人生病 / 挨饿。**

**adventuregamers** 写得最准：
> "太多记过，你的工资就会被扣，家里人挨饿生病，把你推进很难的抉择里。"

→ **这是"被动"为什么有张力：你不能不下判断，而判断错了有人替你付代价。**

### 你必须做的判断（这些是道德题，不是逻辑题）

评测里列出的真实抉择：

```
为了一家人团聚，接受一次记过？
为了给小孩买药，收下那笔贿赂？
相信那个戴兜帽的阴谋者，赌上自己的命？
为了让上司高兴，给他朋友通融一次？
```

**20 个结局**，说明这些选择会被记住并累积。

## 三、和"碎纸机 / 工作台"的关系（这段必须写清）

**你最早描述的那种游戏，现在有具体的作品，但它们不是 Papers, Please：**

### Paper Shredder（Embers 开发，2026 冬）

| 项 | 值 | 来源 |
|---|---|---|
| 类型 | 第一人称增量（incremental）模拟 | 3DM / techmash |
| 设定 | 受雇销毁全部机密文件，完成拿 **$1,000,000** | techmash |
| 核心循环 | 碎纸 → 扫纸屑 → 积分 → 升级碎纸机/自动进料/工业扫帚 | techmash |
| 关键角色 | **"幸福主管"（Happiness Manager）**，一直用正能量话术盯着你 | techmash |
| 叙事 | 文件堆下面藏着秘密，越往后越接近"你在销毁证据" | techmash |
| 平台 | Xbox Series X\|S / Xbox PC / Steam / Epic，2026 冬 | techmash |
| 状态 | **已确认加入 Xbox Play Anywhere + 跨购**；是 Steam 上愿望单最高的独立游戏之一 | techmash |

**中文名《碎纸机》**，3DM 有游戏库条目，标签写的是"虚拟现实 物理 心理恐怖 资本主义 休闲"。

### PAPERWORKS: Paper Shredder Inc.（2026 Q4）

另一个同类，设定在**卡在 1987 年的办公室**：搬书 → 扫描 → 碎原件 → 烧残渣换钱。带磁带和光盘要处理。

### After Hours（另一个方向，但机制极像）

**清洁工代替碎纸工，但核心一样**：
```
七个晚上打扫同一层办公室
擦白板 → 之前写的字会透出来
窗户泡沫 → 显出有人在玻璃上写的字
吸尘器 → 从桌下吸出东西
紫外灯 → 显出上一个清洁工留的隐形墨水
找到的东西你决定：留着 / 放回 / 扔掉 / 碎掉 / 放进某人信箱
→ 四个结局，第七晚决定什么能活到早上
```

**这个游戏的"信息获取方式"是全套里最讲究的——线索不是找到的，是"清洁"这个动作带出来的。**

## 四、可引用的原话

**adventuregamers（讲氛围最准）**：
> "尽管你整场游戏都被绑在桌子后面，但周围始终有一个活着的世界，它的运动和阴谋会突然打断你手头的活。"

**adventuregamers（讲手感）**：
> "在桌上把证件扫来扫去，快得让人愉快。盖章的感觉，和现实里一样有结论性。"

**IMDb 剧情一句话**：
> "1982 年，虚构的社会主义国家 Arstotzka，一名边检官必须应付复杂的入境规定、上级的腐败、恐怖分子、一个神秘组织，以及申请入境者各自的私人悲剧。"

**反复出现的台词**：`Glory to Arstotzka!`（阿尔斯托兹卡万岁）

## 五、可以写的角度（候选）

1. **一个人、自研引擎、5–10 万美元，卖了几百万份**——这个类型的经济学起点
2. **"你不动，别人走向你"**——方向反转为什么有张力
3. **记过 → 扣钱 → 家里挨饿**：惩罚不是 Game Over，是让别人付代价
4. **2026 年这个机制回来了**：Paper Shredder 的"幸福主管"，是 Papers Please 上司的当代版本
5. **After Hours 的线索设计**：擦白板才看见之前的字——信息不是搜到的，是劳动出来的
